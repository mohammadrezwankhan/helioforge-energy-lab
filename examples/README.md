# Reproducible synthetic examples

All inputs are illustrative, not a real customer tariff, project or forecast. Each `*-default.json` contains the complete API input contract for its named model. `dashboard-snapshot.json` is generated by the Python engines and feeds the standalone preview.

## Hand-verifiable storage case

`storage-hand-check.json` contains two one-hour periods, a 2 kWh / 1 kW battery, no losses or wear, zero initial/final energy, and a 1 kWh load in period two. Charge 1 kWh at EUR 0.10 and discharge it in the EUR 0.30 period. Baseline cost is EUR 0.30, optimized cost EUR 0.10 and savings EUR 0.20. This is a regression benchmark, not an annual business case.

With the API running, from the repository root:

```bash
curl -X POST http://127.0.0.1:8000/api/storage/optimize \
  -H "Content-Type: application/json" --data-binary @examples/storage-hand-check.json
```

Windows PowerShell can use `curl.exe` for the same HTTP request. Stored runs can be inspected through `/api/runs` and downloaded from the dashboard history. Do not commit modified examples containing private project data.
