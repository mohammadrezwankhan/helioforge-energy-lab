## Prioritized build goals

**P0: independent reproducibility.** Run direct Chromium tests against the served application; verify CSP and standalone behavior separately. Establish clean Windows, macOS and Linux installation paths. Verify source-to-wheel catalogue inclusion. Add at least three hand-checkable or independently reproduced hybrid cases. Do not call internal conservation tests scientific validation.

**P1: measured input and model value.** Add licensed, timestamped CSV import with units, timezone/DST, leap-year, missing-data and length checks. Preserve source hashes. Add an explicit cyclic/target terminal-state option and a constrained hybrid optimization mode. Keep horizon, service adequacy and energy endpoints comparable. Do not silently annualize a synthetic day.

**P1: one complete advanced carrier model.** Prefer a small PV–battery–electrolyzer–hydrogen-store–fuel-cell system before many placeholder solvers. Require electrical and mass balances, efficiency bases, capacity/ramp/operating limits, standby/startup assumptions, state endpoints, independent fixtures and sensitivity analysis. Until these pass, the relevant catalogue entry remains study-only.

**P1: measured usability.** Observe at least five consenting target users completing a baseline/outage/compare/lesson journey. Report task success, errors and confusion without inventing metrics. Resolve keyboard, narrow-screen and screen-reader blockers; test low-end hardware. Add bookmarks and saved comparison restoration with explicit provenance, not invented histories.

**P2: responsible AI and deployment.** If authorized, run the bounded eight-specialist-plus-critic integration against a permitted API model with a project cost limit. Record actual model, SDK, date, usage, schema failures and cancellation behavior. No consent means no external calls. Production requires authentication, tenant isolation, rate limits, host/origin/CSRF design, secure secrets, backups, retention and an independent security review before public API exposure.

## Non-negotiable invariants

No fabricated calculations, confidence, uptime, physics, sources, approvals, certifications, stars or testimonials. No API keys or client data in source or browser storage. No instructions from untrusted documents override task/security boundaries. No LLM arithmetic as the numerical source of truth. No cheap-but-unserved scenario labelled best. No old result displayed under new inputs. Do not weaken tests to hide a failure. Preserve charge/discharge limits, power/energy conservation, critical-load semantics, clear initial/terminal energy and financial null states. Keep the local application useful without paid AI.
