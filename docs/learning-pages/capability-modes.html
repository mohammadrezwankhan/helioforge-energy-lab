CAPABILITY GUIDE / FOUR DELIVERY MODES

Choose the mode that fits the question.

HelioForge separates precomputed examples, the browser Terminal, local Python studies, and optional external integrations so the delivery path is visible before interpreting a result.

Written by Mohammad Rezwan Khan · Revised 28 October 2026 · Capability contract 1.0.0

Four distinct modes

  1. Bundled synthetic examples. The public browser edition displays precomputed example results. Editing a study form in that edition does not produce a fresh result for that study.
  2. Bounded browser Terminal. Terminal calculates new deterministic cases over 24 one-hour intervals using a fixed greedy PV, battery and grid policy. It is distinct from the advanced study models and is not an optimizer.
  3. Advanced local Python. The separate local app runs 59 named studies across twelve workspaces, plus existing hybrid and storage engines. Each study contract lists its current equations, inputs, bounds, units and limits.
  4. Opt-in local external providers. Optional integrations may retrieve weather or market data, read configured devices, or send selected evidence to an external AI provider. They are separate, consent-gated, and require their own operator configuration. The public static preview makes no provider calls.

Three task-led starts

  1. Explore a bundled example in the preview and inspect its assumptions.
  2. To calculate a bounded Terminal case, use the Parametric energy workbench in Scenario compare.
  3. To set up advanced local calculations, follow the Python installation guide.

Provider evidence boundary

Provider support varies by connector. A configured key or endpoint is not proof that an external call succeeded. Paid OpenAI execution, most live data feeds, real devices and physical model validation have not been established by these content pages. Check connector prerequisites and observed validation before use.

For exact per-study delivery, schema, fixture and limitation details, open the model registry. For an arithmetic example, see one hand-checkable Terminal hour.
