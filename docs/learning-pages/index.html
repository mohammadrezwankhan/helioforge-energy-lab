How to use these pages

  1. Start with the model version and the data kind attached to an example.
  2. Check field units, equation, time basis, and initial and terminal storage energy.
  3. Find the linked fixture and software tests; keep those claims separate from independent validation.
  4. Write down evidence that is still missing before applying a result to a real project.

These guides explain source and arithmetic. They do not validate a plant, forecast, finance case, legal position, training outcome or release deployment.
