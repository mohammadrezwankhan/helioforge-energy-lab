## HTTP service

The service defines 30 explicit business routes, listed below. FastAPI additionally supplies its framework documentation/OpenAPI routes. Pydantic request models define the authoritative bounds; `StrictModel` forbids extra fields and non-finite numbers, but does not globally set `strict=True`. Some study families add strict typing, and Terminal applies its own validation. Do not generalize one validator's coercion or duplicate-key behavior to every entry path. [apps/api/helioforge/main.py](https://github.com/mohammadrezwankhan/helioforge-energy-lab/blob/fb42eb4d9b0c87e692710e8e867ab5190ea831a7/apps/api/helioforge/main.py), [apps/api/helioforge/schemas.py:9–17](https://github.com/mohammadrezwankhan/helioforge-energy-lab/blob/fb42eb4d9b0c87e692710e8e867ab5190ea831a7/apps/api/helioforge/schemas.py#L9-L17), [apps/api/helioforge/studies.py:37–39](https://github.com/mohammadrezwankhan/helioforge-energy-lab/blob/fb42eb4d9b0c87e692710e8e867ab5190ea831a7/apps/api/helioforge/studies.py#L37-L39).

Host and Origin allow-lists are local deployment boundaries, not authentication. Mutation requests with an Origin must match the configured list; absence of an Origin passes that check. Requests have a 1 MB body limit. Ordinary saved-run reads and calculation routes are not a general authenticated multi-user service. The launcher, rather than the app object alone, forces loopback and disables external AI. [apps/api/helioforge/main.py](https://github.com/mohammadrezwankhan/helioforge-energy-lab/blob/fb42eb4d9b0c87e692710e8e867ab5190ea831a7/apps/api/helioforge/main.py), [launch.py:119–153](https://github.com/mohammadrezwankhan/helioforge-energy-lab/blob/fb42eb4d9b0c87e692710e8e867ab5190ea831a7/launch.py#L119-L153).

Successful calculation endpoints store inputs and results and return a run ID; saved-run lookup returns an existing record. `GET /api/overview` is a cached synthetic dashboard for one of six market labels, not a live feed. `GET /api/runs` returns the latest 100 saved records. Pilot status transitions and event history are local records, not independently verified commissioning outcomes. [apps/api/helioforge/dashboard.py](https://github.com/mohammadrezwankhan/helioforge-energy-lab/blob/fb42eb4d9b0c87e692710e8e867ab5190ea831a7/apps/api/helioforge/dashboard.py), [apps/api/helioforge/store.py](https://github.com/mohammadrezwankhan/helioforge-energy-lab/blob/fb42eb4d9b0c87e692710e8e867ab5190ea831a7/apps/api/helioforge/store.py).

The core model schemas are `StorageRequest`, `FinanceRequest`, `PVRequest`, `ForecastRequest`, `DriftRequest`, `ReliabilityRequest`, `SustainabilityRequest`, `MARequest`, `CouncilRequest` and `PilotUpdate`. Hybrid uses `HybridRequest`; studies use `{study, inputs}` with a registered ID and at most 40 input keys. The [parameter reference](../math-and-physics/PARAMETERS_AND_SYMBOLS.md) and [59-study atlas](../math-and-physics/STUDY_MODEL_ATLAS.md) link their precise implementation/schema contracts. [apps/api/helioforge/schemas.py](https://github.com/mohammadrezwankhan/helioforge-energy-lab/blob/fb42eb4d9b0c87e692710e8e867ab5190ea831a7/apps/api/helioforge/schemas.py), [apps/api/helioforge/hybrid.py](https://github.com/mohammadrezwankhan/helioforge-energy-lab/blob/fb42eb4d9b0c87e692710e8e867ab5190ea831a7/apps/api/helioforge/hybrid.py), [apps/api/helioforge/studies.py](https://github.com/mohammadrezwankhan/helioforge-energy-lab/blob/fb42eb4d9b0c87e692710e8e867ab5190ea831a7/apps/api/helioforge/studies.py).

Example local request after the launcher starts:

```sh
curl --fail-with-body http://127.0.0.1:8000/api/health
curl --fail-with-body -H 'Content-Type: application/json' \
  -d '{"study":"hybrid-controls","inputs":{}}' \
  http://127.0.0.1:8000/api/studies/evaluate
```

These curl commands are usage examples; the review executed the native study function and existing API tests, not a newly launched HTTP session. A failed client request or timeout does not guarantee that a submitted calculation was cancelled before it was saved. Inspect history before repeating a mutation.

## Python and operating-system entry points

`python launch.py [--check] [--no-browser] [--port PORT]` is the packaged launcher. The project Makefile and scripts provide build/test/publication utilities; they are development entry points, not additional REST endpoints. Scientific Python functions are documented by source location and request model in the [equations](../math-and-physics/EQUATIONS_AND_DERIVATIONS.md) and [atlas](../math-and-physics/STUDY_MODEL_ATLAS.md). No Terminal REST endpoint is defined. ## Browser Terminal contract

The Terminal's 11 fields are `pvKw`, `batteryKwh`, `batteryKw`, `loadKw`, `gridKw`, `roundtripEfficiency`, `initialSocFraction`, `minSocFraction`, `maxSocFraction`, `importPrice`, `exportPrice`. Inputs must be finite numbers; booleans are not accepted as numbers. SOC fractions must be ordered; zero storage requires zero battery power. It produces exactly 24 hourly rows with supply, demand, charge/discharge, SOC and conservation residuals. `CONVERGED` means the direct recurrence completed; `iterations` is null. [apps/web/src/terminal-engine.ts](https://github.com/mohammadrezwankhan/helioforge-energy-lab/blob/fb42eb4d9b0c87e692710e8e867ab5190ea831a7/apps/web/src/terminal-engine.ts), [apps/api/helioforge/engines/terminal.py](https://github.com/mohammadrezwankhan/helioforge-energy-lab/blob/fb42eb4d9b0c87e692710e8e867ab5190ea831a7/apps/api/helioforge/engines/terminal.py).

Pin a completed result as A, change inputs and run B, then inspect absolute `B−A` and relative `100(B−A)/|A|` differences. A zero baseline makes the relative value undefined. Sweeps accept one or two axes, 2–21 values per axis and at most 441 points; logarithmic endpoints must be positive. Invalid points stay visible. Ranking is lexicographic by unserved demand, period cost, absolute stored-energy change and index. Conditional sampled Pareto sets compare matching total demand and served energy; they do not imply energy-neutral or globally optimized alternatives. Local sensitivity is one-at-a-time finite difference elasticity, not a Sobol index. [apps/web/src/terminal-engine.ts](https://github.com/mohammadrezwankhan/helioforge-energy-lab/blob/fb42eb4d9b0c87e692710e8e867ab5190ea831a7/apps/web/src/terminal-engine.ts), [apps/web/src/terminal-ui.ts](https://github.com/mohammadrezwankhan/helioforge-energy-lab/blob/fb42eb4d9b0c87e692710e8e867ab5190ea831a7/apps/web/src/terminal-ui.ts).

The command palette accepts `:sweep`, `:pin`, `:diff`, `:preset reference|island|solar|storage`, `:reset`, and `:export json|csv|md`. These are browser commands, not shell commands. Ctrl/Cmd+K opens the palette; `:` outside an input starts a command. [apps/web/src/champion-controller.ts:487–541](https://github.com/mohammadrezwankhan/helioforge-energy-lab/blob/fb42eb4d9b0c87e692710e8e867ab5190ea831a7/apps/web/src/champion-controller.ts#L487-L541), [apps/web/src/terminal-ui.ts](https://github.com/mohammadrezwankhan/helioforge-energy-lab/blob/fb42eb4d9b0c87e692710e8e867ab5190ea831a7/apps/web/src/terminal-ui.ts).

Terminal JSON uses `helioforge.terminal.v1`. Its payload digest excludes the generated timestamp; import checks schema, inputs and solver contract, recomputes the digest and recomputes the full result with the current engine. This is deterministic integrity checking, not signer identity. Manifest upload is capped at 250,000 bytes; share-query input is bounded at 12,000 characters. CSV/Markdown export includes model boundaries. [apps/web/src/terminal-manifest.ts](https://github.com/mohammadrezwankhan/helioforge-energy-lab/blob/fb42eb4d9b0c87e692710e8e867ab5190ea831a7/apps/web/src/terminal-manifest.ts), [apps/web/src/terminal-ui.ts](https://github.com/mohammadrezwankhan/helioforge-energy-lab/blob/fb42eb4d9b0c87e692710e8e867ab5190ea831a7/apps/web/src/terminal-ui.ts).
