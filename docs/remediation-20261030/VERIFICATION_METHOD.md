Check every file against the immutable CI build receipt before packaging a direct-upload ZIP. Upload only that site to `mkgrid-helioforge`; retain the prior deployment and response-header transform as a paired rollback record.

The command-line OAuth callback rejected mismatched state, so no security check was bypassed. The user selected Chrome's Rezwan profile and confirmed the existing HelioForge project. The signed-in dashboard provides the direct-upload path. A dashboard upload may omit a Git commit label; the release receipt must then bind the deployment to the verified ZIP, CI artifact, public manifest source revision and exact retrieved bytes without inventing deployment metadata.
