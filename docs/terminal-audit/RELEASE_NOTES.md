# HelioForge Terminal1.0.0

A major release of the twelve-view energy research application. Terminal surfaces, Martian Mono typography, hairline structure and compact controls replace the former decorative interface. Existing numerical models, catalogue, lessons, study workflows and exports remain available.

The added synthetic single-bus model solves24direct hourly energy balances. It supports bounded one/two-axis linear/log sweeps, conditional sampled Pareto frontiers, signed local-elasticity tornado ranking, pinned A/B deltas, conservation telemetry and regime explanations. It is not a dispatch optimizer or a thermal/grid-dynamics model.

Commands: `:sweep`, `:pin`, `:diff`, `:preset reference|island|solar|storage`, `:reset`, `:export json|csv|md`. Ctrl+K or `:` opens the existing command palette. JSON import verifies SHA-256 and reproduces the complete output series. Query URLs reproduce inputs under the versioned model. Digests identify state; they do not authenticate a signer.

Review AUDIT_MANIFEST.md, ANALYTICAL_MODEL.md, PRESERVATION.md, VERIFICATION.md and HALLMARK_SCORECARD.md for executed evidence and limits. Browser work and static publication do not imply independent scientific certification.
