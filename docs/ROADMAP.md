# Roadmap: from research release to operational evidence platform

This document describes **future work**, not hidden shipped capabilities.

## Release 0.1 foundation — retained

Nine working browser views; physically constrained short-horizon storage dispatch; independent finance/PV/M&A models; drift, Weibull and carbon screens; seeded price scenarios; source register; pilot evidence persistence; audit-run exports; optional bounded agent adapter; tests and a standalone preview.

## Release 0.2 — included

36 architectures (19 screens / 17 study-only), 24 scenarios, 36 lessons, three new workspaces, original software 3D, explained tags, strict setup import/export, exact saved hybrid-run review evidence, eight specialist roles plus critic, 285 runnable-pair regressions and responsive browser checks. Read FINAL_AUDIT for what was actually tested.

## Next: close the data-to-value gap

1. **Annual site-data pipeline.** Timestamped 8,760-/35,040-interval imports with DST, leap years, units, missing-data checks, tariff billing periods and replayable source hashes. Keep site identifiers and commercial data outside Git.
2. **True value-stream co-optimization.** Separate energy, peak charges, ancillary services, availability fees and penalties. Model eligibility, mutually exclusive commitments, power/energy headroom, rebound and settlement. Never sum independently optimized revenues.
3. **Annual dispatch-to-finance bridge.** Reconcile meter energy, tariff costs and contracted cash receipts to annual CFADS. Add cyclic/calendar degradation, warranty limits, augmentation funding, taxes, reserves, sculpted debt and contract/default scenarios.
4. **Reviewed geography packs.** Effective-dated primary rules, reviewer/expiry fields and rule fixtures for France, Germany, Spain, Italy, Netherlands and Great Britain. Ingest only authorized data. Source pages alone do not close this milestone.

## Then: calibrated science and diligence

Fit reliability models with censoring and validation; connect weather-normalized asset KPIs and interpretable fault evidence. Add geospatial PV layout constraints and engineering diligence checklists. Import reviewed lifecycle inventories and ecological baseline/monitoring protocols. Extend the annual price demonstration with fundamental drivers, hourly capture, out-of-sample tests and scenario documentation.

PV/wind/BESS M&A work should combine data-room evidence, acquisition structure, land/grid/permitting/warranty review, technology-specific yield and condition risks, taxes and bid sensitivities. A technology-neutral EV/EBITDA ratio is not enough.

## Production gate

Add identity, roles, per-tenant storage, secrets management, TLS, explicit origin/host policy, anti-CSRF design, worker queues, cancellation, rate limits, provider budgets, structured observability, backup/restore tests, retention and deletion, deployment threat model, dependency scanning and an independent security review. Introduce a durable, access-controlled audit chain where compliance requires it.

## Good first issues

A regression for an extreme but valid tariff; browser keyboard/focus improvements; clearer units and empty states; a reviewed source-record schema; comparison-run restoration; independent hand calculations; localization without changing numerical semantics.
