# Roadmap completion and external evidence — 18 October 2026

The software implementation now covers all twelve views and 59 executable research studies. The original 39-study delivery is retained as [historical evidence](DELIVERY.md); twenty further studies, evidence connectors, prerequisite gates, comparison scenes and external council rounds close its implementation gaps. All numerical studies can run through the local Python API. The public static edition carries reproducible examples and exports; it explicitly disables new backend calculations and provider/device operations.

“Implemented” below means working software under the documented assumptions. Scientific calibration, legal applicability, human identity and professional approval are separate evidence requirements. The original hybrid catalogue still has 19 hourly runnable architectures and 17 study-only architectures. Specialized studies do not turn every advanced architecture into a validated plant simulator.

## Shared implementation and evidence

- Browser execution uses vanilla TypeScript/HTML/CSS with no runtime packages. Numerical work remains in Python. Missing/nonfinite data and stale results fail visibly; inputs, equations, limits, sources and evidence digests accompany calculations.
- Imports are bounded, audited in local SQLite and labeled unverified. Provider URLs are fixed/allow-listed, credentials remain server-side, and device access is read-only. [Connector setup](CONNECTORS.md) documents prerequisites and exact limits.
- Decorative motion follows reduced-motion controls; keyboard tariff editing, prerequisite checks, independently controlled scenes and 390px layouts are browser-tested. Automated axe checks include enhanced contrast. Actual screen-reader/keyboard usability sessions across assistive technologies, device performance and a formal WCAG conformance review remain external.
- This release does not claim an award, universal 60 FPS, accredited certificates, formal legal notices, independent signer identities or certified engineering. SHA-256 proves content identity; a digital signature proves possession of its key.
- The independent completion review closed the rare-event confidence-interval, bearing-envelope score and discrete ICP retention findings with regression tests. [Verification](VERIFICATION.md) records software proof. Release publication is identified by Git commit, live app manifest and a signed release receipt.
