User scope confirmed 17 October 2026: implement the entire roadmap across all twelve views. The initial preservation sprint is included in this larger scope.

## Architecture

Keep the canonical TypeScript/Canvas2D source and Python engines. Port artifact-only visuals into source. Add a catalogue of 36 distinct content studies plus three supporting tools, with strict Python inputs, source-backed equations, reproducible defaults, provenance, and view-specific interactive presentation. Existing 19 runnable / 17 study-only hybrid classifications stay intact: the new simplified studies do not silently upgrade those architectures.

The shared experiment shell handles keyboard controls, visible errors and stale results, JSON inputs, exports and provenance. Page-specific controls handle interval/year/transcript scrubbing, financial sculpting, evidence inspection, learning progression, geographic/land polygons and pilot moves. Advanced engineering screens are reduced-order educational experiments; site-specific compliance and field validation remain evidence requirements. All requested features are tracked in a page-by-page delivery ledger, including prerequisites which cannot truthfully be manufactured.

## Acceptance and review focus

No fake real-time sources, fabricated legal rules, scientific calibration, accreditation, awards, externally executed agents or multisignature claims. Null DSCR/IRR, physical conservation, input bounds, data provenance and offline capability remain explicit. No annualization of the original 24-hour dispatch. Source builds reproduce intended graphics. Every study has a successful default, meaningful numerical tests, exportable inputs/results and visible limitations. Final verification distinguishes local completion from deployment and live-provider testing.
