# HelioForge Energy Lab: voiceover draft

Interactive hybrid-energy research and learning workbench with auditable numerical screens and a local Python API. The example runs locally. Start from the README, open a supplied record, and inspect what is known, what is synthetic, and what stays on the device. The source and tests let you inspect the rule behind the interface. This is a demonstration under documented limits. If this workflow is useful, try one reproducible contribution from the project quest list.
