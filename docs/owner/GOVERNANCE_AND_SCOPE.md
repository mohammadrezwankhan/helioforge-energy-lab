## Proposed accountable review gates

| Proposed change | Required reviewer or gate |
| --- | --- |
| Equation, solver or default change | Engineering model maintainer, regression evidence and applicable independent domain review |
| External metering/market/provider data | Data owner, contract/rights/privacy, provenance/vintage and consent check |
| Field device integration | Electrical safety/operations authority, non-destructive test and facility-approved scope |
| Public local API | New authentication/authorization, TLS, threat assessment, tenancy and retention design |
| Release or public-site publication | Code owner, protected CI, artifact hash/CSP and deployment receipt |
| AI-backed optional analysis | Operator-approved privacy/consent, API key handling and spending limits |

No specific human has been assigned these roles by this page; no external engineering certification, professional approval, investor recommendation or field operational permission is implied.
