## Start here

The source offers 12 workspaces with **59 distinct local Python research studies**, generated example outputs for a static browser preview, a *separate* deterministic 24-hour Terminal energy-balance calculator, and opt-in local external integrations requiring consent. The [capability contract](CAPABILITIES.md) and [model registry](MODEL_REGISTRY.md) distinguish these four delivery modes.
